# Contributing

These are unofficial community tools. See [DISCLAIMER.md](DISCLAIMER.md).

## Bugs and corrections

- Tool bug: open a [tool bug issue](https://github.com/beau-finopsorg/focus-tools/issues/new?template=tool-bug.yml).
- Schema map correction: open a [schema map correction issue](https://github.com/beau-finopsorg/focus-tools/issues/new?template=schema-map-correction.yml) and link the specification text that supports it.

## Pull requests

- Keep each pull request small and about one thing.
- Match the style of the code around your change.
- Check schema map changes against the published specification for that version.
- Mark anything for an unreleased specification version as a candidate / pre-release.
- Do not add logos, trademark symbols, or official-looking footers.
- Write plainly. No marketing language.
