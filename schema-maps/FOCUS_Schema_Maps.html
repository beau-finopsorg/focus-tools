New = added since the previous version · Changed = definition, format, or feature level materially changed · Deprecated = marked for removal · Mandatory = FOCUS requires this column unconditionally (excludes columns required only when a provider supports a given capability) · Joins follow the FOCUS dataset relationships (no enforced keys). A column with several flags shows one stripe per flag. Open “What changed” under each version for the full list.

About these joins. FOCUS does not define primary or foreign keys. The JOIN KEY (owner side) and JOIN (referencing side) badges mark the columns FOCUS uses to join datasets — defined from v1.3 in each dataset’s join table — not enforced database keys. Note: Cost and Usage ↔ Contract Commitment joins on Contract Commitment ID, which lives inside the JSON object array in the Contract Applied column (not a scalar column). The v1.4 Invoice Detail and Billing Period joins are multi-column (Invoice Issuer Name + Invoice ID [+ Invoice Detail ID]; Billing Period Start + Invoice Issuer Name). The v1.5 SKU Price dataset (preview) joins Cost and Usage on SKU Price ID within the same Service Provider Name; resolving one price also matches Contract ID (from Contract Applied), Pricing Currency, a single Unit Price Type, and the charge period against SKU Price Effective Start/End. SKU Price can also join Contract Commitment on Contract ID.
