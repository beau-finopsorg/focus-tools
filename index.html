FOCUS tools

Free reference tools for working with the FinOps Open Cost and Usage Specification (FOCUS): schema maps for each version and a set of reference architectures.

The specification itself lives at focus.finops.org. Use it as the source of truth.

Schema maps

One-page maps of the FOCUS columns, grouped by category, for each specification version.

Open the interactive schema maps Versions 1.0, 1.1, 1.2, 1.3, 1.4, and 1.5 (candidate) in one page.

Spec compare

Open FOCUSed Spec Compare Word-level diff of any section of the published specification between two versions (1.0 through 1.4). Reads the spec live from focus.finops.org.
